🌐 Personal Portfolio Website

This is my personal portfolio website developed using HTML, CSS, and JavaScript.
It showcases my profile, skills, projects, and contact details with interactive and dynamic frontend features.

This project reflects my learning journey as a B.Tech CSE (AI & ML) student and my growing interest in frontend development.

📌 Features
🧭 Navigation

Smooth navigation between sections (Home, About, Skills, Projects, Contact)

Sticky navigation bar for easy access

🌗 Dark / Light Mode

Theme toggle button implemented using JavaScript

Enhances user experience and accessibility

⌨️ Typing Animation

Dynamic typing effect for my name using JavaScript

Adds a modern and interactive feel to the homepage

👤 About Me Section

Personal introduction and career goals

Clear and structured content layout

🛠 Skills Section

Displays technical skills including programming, AI/ML basics, and web development

💼 Projects Section

Project cards with images, descriptions, and GitHub links

JavaScript-based project filtering: All , Web , AI

📞 Contact Section

Contact details (Email, GitHub, LinkedIn)

Simple contact form UI (frontend only)

📱 Responsive Design

Works well on desktop and mobile devices using CSS

🛠 Technologies Used

HTML5 – Structure and semantic layout

CSS3 – Styling, responsiveness, and UI design

JavaScript (ES6) - DOM manipulation , Event handling , Theme toggling , Typing animation , Project filtering logic

🎯 Purpose of This Project

1. Build a professional personal portfolio

2. Practice core frontend development skills

3. Learn how to add interactivity using JavaScript

4. reate a base project that can be expanded in the future
